# R Data Analytics Projects

## 📊 About This Repository

This repository contains five beginner-friendly data analytics projects developed using **R Programming** and **Shiny**.

The projects demonstrate data analysis, visualization, statistical calculations, and interactive web dashboards using R.

---

## 🚀 Projects

### 1. Student Performance Analysis

**Objective:**  
To analyze student performance data and understand marks and academic performance using R.

**Key Features:**
- Student performance analysis
- Average marks calculation
- Highest and lowest marks
- Performance visualization
- Interactive Shiny dashboard

**Technology Used:**
- R Programming
- Shiny
- Base R Visualization

**File:** `Project1_app.R`

---

### 2. Personal Expense Analysis

**Objective:**  
To analyze personal expenses and understand spending patterns across different categories.

**Key Features:**
- Total expense calculation
- Average expense calculation
- Highest expense identification
- Category-wise expense analysis
- Expense visualization

**Technology Used:**
- R Programming
- Shiny
- Base R Visualization

**File:** `Project2_app.R`

**Results:**
- Total Expense: Rs. 2680
- Average Expense: Rs. 268
- Highest Expense: Rs. 500

**Technology Used:**

### 4. Supermarket Sales Analysis

### 5. Hospital Disease Analysis

**Objective:**  
To analyze the number of patients affected by different diseases and visualize disease-wise patient counts.

**Key Features:**
- Total patient calculation
- Number of diseases
- Highest patient count
- Average patient count
- Disease-wise patient chart
- Patient data table

**Technology Used:**
- R Programming
- Shiny
- Base R Visualization

**File:** `Project5_app.R`

**Results:**

- Highest Patients for a Disease: 25
